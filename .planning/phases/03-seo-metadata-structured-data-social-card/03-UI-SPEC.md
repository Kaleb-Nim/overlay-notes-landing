# Phase 3 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

**Scope note:** Phase 3 is a metadata/SEO phase. Its only visual surface is the static
1200×630 Open Graph social card (`public/og-image.png`). The landing page's own sections
(nav→footer) were designed and built in Phase 2 (`02-UI-SPEC.md`) and are LOCKED — this
document does not redesign or re-spec them. Everything else in Phase 3 (`<title>`, meta
description, JSON-LD, robots/sitemap, headers) is non-visual and out of this contract's
scope; those values are already locked verbatim in `03-CONTEXT.md`.

## OG Social Card — Canvas & Layout

**Hard constraint (ASSET-01):** exactly **1200×630px**. No responsive variants — this is a single fixed-size, deterministically-rendered static PNG.

**Composition (locked in `03-CONTEXT.md` — "Screenshot + text panel"):** a left paper-textured text panel and a right cropped, matted frame of `public/annotate-hero.png`. Full layout below.

### Canvas background

Reuse the site's ruled-paper texture verbatim across the full 1200×630 canvas (both panels sit on top of it — do not give the right panel a different flat fill):

```css
background:
  repeating-linear-gradient(var(--paper) 0 31px, var(--rule) 31px 32px),
  linear-gradient(var(--paper), var(--paper));
```

This is copied unchanged from `app/globals.css` `body{}` — same 31px/32px rhythm, same tokens.

### Left text panel — x: 0–460 (width 460px), y: 0–630 (full height)

- Padding: `56px 32px 56px 56px` (top/bottom 56, right 32 before the divide, left 56)
- Content is a vertically-centered (`justify-content: center`), left-aligned flex column, max-width **340px** so the headline wraps naturally
- Stack, top to bottom:

| Order | Element | Copy | Gap after |
|-------|---------|------|-----------|
| 1 | Headline | "Draw & **annotate** notes on any webpage" | 24px |
| 2 | Wordmark | "▸ Overlay Notes" | 16px |
| 3 | Tagline | "Free Chrome extension ☕" | — |

Typography for each element is specified in the Typography table below. The word **"annotate"** in the headline is the one accent-colored span — see Color section.

### Right image panel — x: 460–1200 (width 740px), y: 0–630 (full height)

- No separate background fill — the ruled-paper canvas texture shows through as the mat/margin.
- White-matted photo card, **flat (no rotation)** — see "Deviation from on-page hero treatment" below:
  - Mat rect: inset **20px top / 20px right / 20px bottom / 12px left** within the panel → renders at x: 472–1180, y: 20–610 (708×590px)
  - Mat background: `#ffffff`, `border-radius: 6px`, `box-shadow: 0 16px 30px -12px rgba(20,12,60,.45)` — copied verbatim from `.shot .frame` in `app/globals.css`
  - Inner padding: `8px` white padding inside the mat (matches `.shot .frame{padding:8px}`) → photo render area ≈ 692×574px
  - Photo: `border-radius: 3px` (matches `.shot .frame img{border-radius:3px}`)

**Deviation from on-page hero treatment (deliberate, note for executor):** the live site's `.shot` composition rotates the frame `2deg`, adds a yellow tape strip, a red handwritten side-note, and an arrow pointing at a bottom handwritten note (`app/globals.css` `.shot`/`.tape`/`.note-r`/`.arrow`/`.note-b`). **Do not port these decorations to the OG card.** They rely on extra canvas margin to avoid clipping at their rotated bounding box, which the fixed 1200×630 crop does not have — copying them verbatim would clip content at the card edges and look broken in a social preview. Reuse only the white-mat + hard-shadow idiom (frame background, padding, radius, shadow); keep the frame unrotated and undecorated.

### Recommended source crop (public/annotate-hero.png, 1280×800)

CONTEXT.md leaves the exact crop rectangle to implementation discretion. Recommended default, chosen by inspecting the source image to maximize marker-annotation density and legibility at thumbnail scale while excluding non-brand chrome:

- **Crop rect:** `x: 400, y: 170, width: 780, height: 630` (bottom-right corner lands at 1180,800 — inside the 1280×800 source bounds)
- **Aspect of crop:** 780/630 ≈ 1.238, close to the mat's inner render area aspect (692/574 ≈ 1.206) — scale-to-fill with negligible additional crop, no distortion
- **Rationale:** excludes the left Excalidraw tool sidebar (x: 0–215, stroke/background/opacity controls — not relevant to the value prop) and the top browser chrome/address bar (y: 0–170) which renders illegibly small at OG thumbnail size. Includes the richest annotation cluster in the source screenshot: the "primitive types" boxed callout, the "strong vs weak idk actly" arrow+underline, "Arrays with int?" note, and the "Never seen this prob..." bracket-underline — the clearest visual evidence of marker-on-webpage annotation.
- This is a **default, not a lock** — if visual QA during Phase 3 execution finds a tighter/better crop, adjusting these four numbers is within scope; the composition rules above (flat, matted, no rotation, no decorations) are not.

## Typography

Card-specific type scale (3 sizes, 2 weights — both within the researcher's declared limits):

| Role | Size | Weight | Line Height | Font |
|------|------|--------|-------------|------|
| Display (headline) | 44px | 700 | 1.05 | Shantell Sans |
| Label (wordmark) | 22px | 700 | 1.0 | Shantell Sans |
| Body (tagline) | 18px | 600 | 1.4 | Public Sans |
| Heading | not used | — | — | This card has exactly 3 text elements per the locked composition (`03-CONTEXT.md`) — no separate heading role |

Fit check (documented, not a runtime concern since the render is deterministic and build-time): headline at 44px/1.05 wrapped to ~340px max-width renders at most 4 lines (~184px), + 24px gap + wordmark 22px + 16px gap + tagline ~25px ≈ 271px total content-stack height, well inside the 518px available in the 630px-tall panel after 56px top/bottom padding. No overflow risk with the locked copy strings.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#f6f1e7` (`--paper`) | Full-canvas ruled-paper background (both panels) |
| Secondary (30%) | `#ffffff` | White mat/frame behind the cropped screenshot (right panel) |
| Accent (10%) | `#5b3df5` (`--purple`) | Reserved for exactly two elements — see below |
| Destructive | not applicable | No destructive actions on a static image asset |

**Accent (`--purple`) reserved for:**
1. The word **"annotate"** within the headline — colored span, mirroring the existing `.hero h1 span{color:var(--purple)}` pattern already used on the live page for the same word-emphasis idiom.
2. The **"▸" chevron glyph** in the wordmark "▸ Overlay Notes".

No other element on the card uses purple — the crop photo itself is a real screenshot (not brand-recolored) and the mat is white per Secondary.

**Text colors (not part of the 60/30/10 surface split, documented for completeness):**
- Headline body text: `#1c1830` (`--head`)
- Wordmark "Overlay Notes" text: `#211d2e` (`--ink`)
- Tagline text: `#4a4560` (`--body`)
