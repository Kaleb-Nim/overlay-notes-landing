## Phase Goal

**As a** person sharing the page's link on LinkedIn or another social platform, **I want to**
see a real 1200×630 social card that composites the annotate screenshot with the product
name and value proposition, **so that** the shared link renders a proper, on-brand preview
instead of a broken or generic thumbnail.

_(Derived faithfully from ROADMAP.md Phase 3 Goal — no scope invented.)_
