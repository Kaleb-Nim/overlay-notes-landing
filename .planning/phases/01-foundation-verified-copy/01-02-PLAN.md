## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Author-supplied copy → shipped page | All strings in `lib/content.ts` are build-time-authored; there is no request/cookie/query-param/third-party-fetch input surface |
| Claim → policy compliance | The banned-term scan is the boundary that keeps Chrome Web Store / Google spam-policy violations out of the page copy |

This plan produces only static TypeScript content and a build-time verification script — no auth,
no sessions, no user input, no runtime data handling (RESEARCH Security Domain, V5 Input Validation
= not applicable). The only meaningful risk is a policy/claim-integrity failure, mitigated by the
traceability check, plus generic supply-chain risk (already handled in Plan 01-01's install).
