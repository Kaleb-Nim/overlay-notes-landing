## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| visitor browser -> static prerendered HTML | the page is fully static; no request data, forms, or user input is processed |
| page -> external destinations | CTAs/footer link out to Chrome Web Store, GitHub, Buy Me a Coffee, github.io privacy, excalidraw.com |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-02 | Spoofing | CTA / footer hrefs | medium | mitigate | Every outbound href is a hardcoded, locked literal verified verbatim against REQUIREMENTS.md; tests/landing.spec.ts asserts the exact Web Store / repo / Buy-Me-a-Coffee / github.io URLs, so a wrong or swapped destination fails the gate. |
| T-02-03 | Tampering (reverse tabnabbing) | external links | low | accept | Prototype links navigate in the same tab (no target="_blank"), so no window.opener handle is exposed. If the executor adds target="_blank" to any link, it must also add rel="noopener noreferrer"; absent that, same-tab navigation carries no tabnabbing risk. |
| T-02-04 | Information disclosure | stale prototype `<head>` | low | mitigate | Defect fix #5: none of the prototype's `<head>` (which still points at kaleb-nim.github.io) is ported into the body. The one github.io URL in the body is the intentional footer privacy link (asserted exactly once). |
</threat_model>
