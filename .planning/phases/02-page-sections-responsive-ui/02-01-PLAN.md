## Phase Goal (MVP user story)

**As a** visitor arriving from a search result or a shared link, **I want to** see the complete Overlay Notes landing page — every section from nav to footer at the prototype's design fidelity, with working links and no layout breakage on any device or motion preference — **so that** I understand what the extension does and can click through to install it.

This plan builds none of the visible sections; it activates the already-written end-to-end contract (tests/landing.spec.ts) and lays the CSS/asset foundation the sections render against. In MVP terms: the failing e2e test already exists from Phase 1 — installing Playwright turns it into a live RED gate that Plan 02-02 will turn GREEN.
